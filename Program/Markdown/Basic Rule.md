# Markdown 知识库索引

> Markdown 语法速查笔记入口。遇到问题直接点进对应分册查阅。

## 目录

- [[基础语法]] —— 标题、列表、链接、图片、表格、代码等核心语法（覆盖 90% 场景）
- [[扩展语法]] —— 脚注、高亮、数学公式、Mermaid 图表、折叠、HTML 等增强语法
- [[Obsidian 语法]] —— 双链、块引用、嵌入、标签、Callout、Frontmatter 等 Obsidian 专属功能

## 快速速查

| 需求 | 语法 |
|------|------|
| 标题 | `# 标题` |
| 粗体 / 斜体 | `**粗**` / `*斜*` |
| 列表 | `- 项` / `1. 项` |
| 任务 | `- [ ] 待办` |
| 链接 | `[文字](url)` |
| 图片 | `![描述](url)` |
| 行内代码 | `` `code` `` |
| 引用 | `> 引用` |
| 分割线 | `---` |
| 表格 | `\| A \| B \|` |
| 双链（Obsidian） | `[[笔记名]]` |
| 高亮 | `==文字==` |
| 数学公式 | `$E=mc^2$` |

## 使用建议

- 日常写作先看 [[基础语法]]，足够应付大多数情况。
- 需要公式、图表、折叠时查 [[扩展语法]]。
- 在 Obsidian 里做双链笔记时查 [[Obsidian 语法]]。
