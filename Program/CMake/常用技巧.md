# CMake 常用技巧

> 日常构建中高频用到的实用配置与命令。

## 构建类型（Debug / Release）

```cmake
if(NOT CMAKE_BUILD_TYPE)
    set(CMAKE_BUILD_TYPE Release)   # 默认 Release
endif()
```

命令行指定：
```bash
cmake -B build -DCMAKE_BUILD_TYPE=Debug
```

常见类型：`Debug`（带调试信息）、`Release`（优化）、`RelWithDebInfo`、`MinSizeRel`。

## 定义可选开关

```cmake
option(BUILD_TESTS "是否构建测试" ON)

if(BUILD_TESTS)
    add_subdirectory(tests)
endif()
```

命令行覆盖：`cmake -B build -DBUILD_TESTS=OFF`

## 指定输出目录

```cmake
set(CMAKE_RUNTIME_OUTPUT_DIRECTORY ${CMAKE_BINARY_DIR}/bin)   # 可执行文件
set(CMAKE_LIBRARY_OUTPUT_DIRECTORY ${CMAKE_BINARY_DIR}/lib)   # 动态库
set(CMAKE_ARCHIVE_OUTPUT_DIRECTORY ${CMAKE_BINARY_DIR}/lib)   # 静态库
```

## 导出编译数据库

供 clangd、VSCode 等工具做代码补全 / 跳转：

```cmake
set(CMAKE_EXPORT_COMPILE_COMMANDS ON)   # 生成 compile_commands.json
```

## 安装规则

```cmake
install(TARGETS app DESTINATION bin)
install(FILES config.ini DESTINATION etc)
install(DIRECTORY include/ DESTINATION include)
```

执行：`cmake --install build --prefix /your/path`

## 常用命令行参数

| 命令 | 作用 |
|------|------|
| `cmake -B build` | 生成构建系统到 build 目录 |
| `cmake -B build -G Ninja` | 指定生成器为 Ninja |
| `cmake --build build` | 编译 |
| `cmake --build build -j 8` | 8 线程并行编译 |
| `cmake --build build --target clean` | 清理 |
| `cmake --build build --config Release` | 指定配置（多配置生成器） |
| `cmake --install build` | 执行安装 |
| `-D VAR=value` | 定义缓存变量 |

## 打印调试信息

```cmake
message(STATUS "普通信息")
message(WARNING "警告")
message(FATAL_ERROR "致命错误，终止配置")

# 查看变量值
message(STATUS "源码目录 = ${CMAKE_SOURCE_DIR}")
```

## 生成器表达式（Generator Expression）

在构建时才求值，常用于按配置区分：

```cmake
target_compile_definitions(app PRIVATE
    $<$<CONFIG:Debug>:DEBUG_BUILD>       # 仅 Debug 定义
)

target_compile_options(app PRIVATE
    $<$<CXX_COMPILER_ID:MSVC>:/W4>       # MSVC 用 /W4
    $<$<CXX_COMPILER_ID:GNU>:-Wall>      # GCC 用 -Wall
)
```

## 推荐目录结构

```text
MyProject/
├── CMakeLists.txt          # 顶层
├── include/                # 公共头文件
├── src/
│   └── CMakeLists.txt
├── lib/
│   └── CMakeLists.txt
└── tests/
    └── CMakeLists.txt
```
