# CMake 基础语法

> CMakeLists.txt 的核心写法，覆盖日常构建的大部分场景。

## 最小示例

```cmake
cmake_minimum_required(VERSION 3.16)   # 要求的最低 CMake 版本
project(MyApp VERSION 1.0 LANGUAGES CXX)  # 项目名、版本、语言

add_executable(MyApp main.cpp)         # 生成可执行文件
```

构建流程（命令行）：

```bash
cmake -B build            # 在 build 目录生成构建系统
cmake --build build       # 编译
```

## 变量

```cmake
set(MY_VAR "hello")          # 定义变量
message(STATUS "${MY_VAR}")  # 读取用 ${}，打印信息
```

- 变量都是**字符串**类型；多个值用分号或空格分隔即为「列表」。
- 常用内置变量：
  | 变量 | 含义 |
  |------|------|
  | `PROJECT_NAME` | 项目名 |
  | `CMAKE_SOURCE_DIR` | 顶层源码目录 |
  | `CMAKE_BINARY_DIR` | 顶层构建目录 |
  | `CMAKE_CURRENT_SOURCE_DIR` | 当前 CMakeLists 所在目录 |
  | `CMAKE_CXX_STANDARD` | C++ 标准（如 17） |

## 设置 C++ 标准

```cmake
set(CMAKE_CXX_STANDARD 17)          # 使用 C++17
set(CMAKE_CXX_STANDARD_REQUIRED ON) # 强制要求，不降级
```

推荐写法（目标级，见 [[目标与依赖]]）：
```cmake
target_compile_features(MyApp PRIVATE cxx_std_17)
```

## 生成目标

```cmake
add_executable(app main.cpp)              # 可执行文件
add_library(mylib STATIC a.cpp b.cpp)     # 静态库
add_library(mylib SHARED a.cpp b.cpp)     # 动态库
```

## 添加源文件

```cmake
add_executable(app
    main.cpp
    utils.cpp
    core.cpp
)
```

> 不推荐用 `file(GLOB ...)` 自动收集源文件：新增文件后不会自动重新配置。

## 头文件目录

```cmake
target_include_directories(app PRIVATE ${CMAKE_CURRENT_SOURCE_DIR}/include)
```

## 条件判断

```cmake
if(WIN32)
    message(STATUS "Windows 平台")
elseif(UNIX)
    message(STATUS "Unix 平台")
else()
    message(STATUS "其它")
endif()
```

常用条件：`WIN32`、`UNIX`、`APPLE`、`MSVC`、`DEFINED VAR`、`VAR STREQUAL "x"`。

## 循环

```cmake
foreach(item a b c)
    message(STATUS "item = ${item}")
endforeach()
```

## 常用命令速查

| 命令 | 作用 |
|------|------|
| `project()` | 声明项目 |
| `add_executable()` | 生成可执行文件 |
| `add_library()` | 生成库 |
| `target_link_libraries()` | 链接库 |
| `target_include_directories()` | 添加头文件目录 |
| `add_subdirectory()` | 加入子目录 |
| `find_package()` | 查找外部依赖 |
| `install()` | 定义安装规则 |
| `option()` | 定义可选开关 |
