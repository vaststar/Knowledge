# Markdown 基础语法

> 最常用的核心语法，覆盖 90% 日常写作场景。

## 标题

用 `#` 表示，几个 `#` 就是几级标题（共 6 级），`#` 后要加空格。

```markdown
# 一级标题
## 二级标题
### 三级标题
```

## 段落与换行

- **段落**：空一行分隔两段。
- **换行**：行尾加 **两个空格** 再回车，或直接使用空行。

```markdown
第一行末尾有两个空格  
第二行（软换行）

这是新的一段
```

## 强调（粗体 / 斜体）

| 语法 | 效果 |
|------|------|
| `*斜体*` 或 `_斜体_` | *斜体* |
| `**粗体**` 或 `__粗体__` | **粗体** |
| `***粗斜体***` | ***粗斜体*** |
| `~~删除线~~` | ~~删除线~~ |

## 列表

### 无序列表
用 `-`、`*` 或 `+`，效果相同：

```markdown
- 第一项
- 第二项
  - 子项（缩进 2 个空格）
```

### 有序列表
用 `数字.`，序号会自动排列：

```markdown
1. 第一步
2. 第二步
   1. 子步骤
```

### 任务列表
```markdown
- [x] 已完成
- [ ] 未完成
```

## 引用

用 `>`，可嵌套：

```markdown
> 一级引用
>> 二级引用
```

## 代码

### 行内代码
用反引号包裹：`` `code` `` → `code`

### 代码块
用三个反引号包裹，可指定语言高亮：

````markdown
```python
def hello():
    print("Hello")
```
````

## 链接

```markdown
[显示文字](https://example.com)
[带标题](https://example.com "悬停提示")
<https://example.com>   自动链接
```

## 图片

语法与链接类似，前面多一个 `!`：

```markdown
![替代文字](图片地址 "可选标题")
```

## 分割线

单独一行写三个及以上的 `-`、`*` 或 `_`：

```markdown
---
```

## 表格

用 `|` 分隔列，第二行用 `-` 定义对齐方式：

```markdown
| 左对齐 | 居中 | 右对齐 |
|:------|:----:|------:|
| A     | B    | C     |
```

- `:---` 左对齐
- `:--:` 居中
- `---:` 右对齐

## 转义字符

在特殊符号前加 `\` 可原样显示：

```markdown
\* 不会变成斜体 \*
```

常见需转义字符：`\ ` `` ` `` `* _ { } [ ] ( ) # + - . !`
