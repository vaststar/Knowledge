# 应用启动流程

> 原始页面：[App Launch](https://confluence-eng-gpk2.cisco.com/conf/spaces/UC/pages/747939111/App+Launch)

Windows 端 Webex 采用**两阶段启动**：第一次以 Launcher Mode 选择最佳版本并拉起第二个进程，第二个进程以 Loader Mode 加载应用 DLL 进入 Qt 应用。

> 🔴 **已知问题**：第一个进程创建子进程时使用了空的 `STARTUPINFO`，未设置 `STARTF_USESHOWWINDOW`，也未调用 `AllowSetForegroundWindow`，导致新窗口没有前台权限，可能在后台显示。

## 第一次启动（Launcher Mode）

```text
┌─────────────────────────────────────────────────────────────────────────────────┐
│                           第一次启动 (Launcher Mode)                              │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                   │
│  Brainlab 调用:                                                                   │
│  CiscoCollabHost.exe -noframemerging                                             │
│                                                                                   │
│  ┌─────────────────────────────────────────────────────────────────────────┐     │
│  │  spark-windows-host.cpp :: wWinMain()                                    │     │
│  │                                                                          │     │
│  │  1. isInLauncherMode(argc, argv) → TRUE                                  │     │
│  │     (因为参数中没有 .dll 文件)                                             │     │
│  │                                                                          │     │
│  │  2. 找到 CiscoSparkLauncher.dll                                          │     │
│  │     路径: %LOCALAPPDATA%\CiscoSpark\CiscoSparkLauncher.dll               │     │
│  │                                                                          │     │
│  │  3. LoadLibrary(CiscoSparkLauncher.dll)                                  │     │
│  │                                                                          │     │
│  │  4. GetProcAddress("SparkEntryPoint") → 调用入口函数                       │     │
│  └────────────────────────────────┬────────────────────────────────────────┘     │
│                                   │                                               │
│                                   ▼                                               │
│  ┌─────────────────────────────────────────────────────────────────────────┐     │
│  │  WebexVersionSelector :: versionSelectorMain()                           │     │
│  │                                                                          │     │
│  │  1. scanForPossibleDirectories() - 扫描所有可能的 Webex 安装目录          │     │
│  │     - %LOCALAPPDATA%\CiscoSpark\ 下的子目录                              │     │
│  │     - 原始安装目录 (从注册表读取)                                          │     │
│  │                                                                          │     │
│  │  2. findBestCandidate() - 找到最佳版本                                    │     │
│  │     - 比较版本号                                                          │     │
│  │     - 检查是否有崩溃记录                                                   │     │
│  │     - 返回最佳候选目录                                                     │     │
│  │                                                                          │     │
│  │  3. launchWebex(bestCandidate, ...) → 启动第二个进程                      │     │
│  └────────────────────────────────┬────────────────────────────────────────┘     │
│                                   │                                               │
│                                   ▼                                               │
│  ┌─────────────────────────────────────────────────────────────────────────┐     │
│  │  WebexLauncherHelper :: launchWebex()                                    │     │
│  │                     ↓                                                    │     │
│  │  ProcessPlatformHelper :: launchProcess()                                │     │
│  │                     ↓                                                    │     │
│  │  ProcessPlatformHelper :: createProcess()                                │     │
│  │                                                                          │     │
│  │  ┌─────────────────────────────────────────────────────────────────┐    │     │
│  │  │  STARTUPINFO startupInfo = {};  // ← 🔴 问题：空的 STARTUPINFO   │    │     │
│  │  │  PROCESS_INFORMATION processInformation = {};                    │    │     │
│  │  │                                                                  │    │     │
│  │  │  // 构建命令行，包含 DLL 路径                                      │    │     │
│  │  │  command = "CiscoCollabHost.exe" <dir> spark-windows-app.dll ... │    │     │
│  │  │                                                                  │    │     │
│  │  │  CreateProcess(0, command, ..., &startupInfo, ...)               │    │     │
│  │  │                                                                  │    │     │
│  │  │  // 🔴 没有设置 STARTF_USESHOWWINDOW                             │    │     │
│  │  │  // 🔴 没有调用 AllowSetForegroundWindow                         │    │     │
│  │  └─────────────────────────────────────────────────────────────────┘    │     │
│  └─────────────────────────────────────────────────────────────────────────┘     │
│                                                                                   │
│  第一个 CiscoCollabHost.exe 进程退出                                              │
│                                                                                   │
└─────────────────────────────────────────────────────────────────────────────────┘
```

## 第二次启动（Loader Mode）

```text
┌─────────────────────────────────────────────────────────────────────────────────┐
│                           第二次启动 (Loader Mode)                               │
├─────────────────────────────────────────────────────────────────────────────────┤
│                                                                                   │
│  命令行:                                                                          │
│  CiscoCollabHost.exe "C:\...\CiscoSpark\45.x.x.x" spark-windows-app.dll ...      │
│                                                                                   │
│  ┌─────────────────────────────────────────────────────────────────────────┐     │
│  │  spark-windows-host.cpp :: wWinMain()                                    │     │
│  │                                                                          │     │
│  │  1. isInLauncherMode(argc, argv) → FALSE                                 │     │
│  │     (因为参数中有 spark-windows-app.dll)                                  │     │
│  │                                                                          │     │
│  │  2. 加载 spark-windows-app.dll                                           │     │
│  │                                                                          │     │
│  │  3. GetProcAddress("SparkEntryPoint") → 进入 Qt 应用                      │     │
│  └────────────────────────────────┬────────────────────────────────────────┘     │
│                                   │                                               │
│                                   ▼                                               │
│  ┌─────────────────────────────────────────────────────────────────────────┐     │
│  │  main.cpp → ApplicationRunner → MainWindow                               │     │
│  │                                                                          │     │
│  │  窗口创建，但因为父进程没有前台权限，                                         │     │
│  │  新进程也没有前台权限，窗口在后台显示                                          │     │
│  └─────────────────────────────────────────────────────────────────────────┘     │
│                                                                                   │
└─────────────────────────────────────────────────────────────────────────────────┘
```
