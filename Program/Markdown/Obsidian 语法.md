# Obsidian 专属语法

> Obsidian 在标准 Markdown 之上扩展的语法，是知识库双链笔记的核心。

## 内部链接（双链）

```markdown
[[笔记名称]]              链接到另一篇笔记
[[笔记名称|显示别名]]      自定义显示文字
[[笔记名称#标题]]          链接到笔记内某个标题
[[笔记名称#^块ID]]         链接到某个文本块
```

## 块引用

在任意段落末尾加 `^块ID`，即可被其它笔记精准引用：

```markdown
这是一段重要的内容。 ^important

引用它：[[笔记名称#^important]]
```

## 嵌入 / 转载

在链接前加 `!`，可将目标内容直接嵌入当前笔记：

```markdown
![[笔记名称]]              嵌入整篇笔记
![[笔记名称#标题]]         嵌入某个章节
![[图片.png]]             嵌入图片
![[图片.png|300]]         嵌入并指定宽度
![[文档.pdf]]             嵌入 PDF
```

## 标签

```markdown
#标签
#多级/标签
```

- 用于分类与检索，点击可查看所有含该标签的笔记。
- 支持 `#父标签/子标签` 层级结构。

## 标注 / 提示框（Callout）

基于引用语法扩展，用于突出显示：

```markdown
> [!note] 标题
> 这是提示内容。

> [!warning] 警告
> 注意事项写在这里。
```

常用类型：`note` `tip` `info` `warning` `danger` `success` `question` `example` `quote`

可折叠写法：
```markdown
> [!tip]- 默认折叠（+ 为默认展开）
> 隐藏的内容
```

## 注释

被 `%%` 包裹的内容仅在编辑模式可见，预览时隐藏：

```markdown
%% 这是一条注释，不会显示在阅读视图 %%
```

## YAML 元数据（Frontmatter）

写在笔记最顶部，用 `---` 包裹，用于属性、标签、别名等：

```markdown
---
title: 标题
tags: [markdown, 笔记]
aliases: [别名1, 别名2]
created: 2026-07-28
---
```

## 常用快捷操作

| 操作 | 快捷键（默认） |
|------|--------------|
| 打开命令面板 | `Ctrl + P` |
| 快速切换笔记 | `Ctrl + O` |
| 双链自动补全 | 输入 `[[` |
| 插入模板 | 需 Templates 插件 |
